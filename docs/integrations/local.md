# 本地模式接入指南

> 状态：默认可用（已启用）· 无需任何配置
> 清单见 `backend/app/integrations/local.py`

## 简介

本地模式是途排智策的默认集成，**开箱即用，无需任何平台凭据**：

- **存储**：数据保存在内置 SQLite（默认 `data/tupai.db`，可用 `DATABASE_URL` 调整）；
- **通知**：站内消息；
- **审批**：发布审批流在系统内完成（版本审批后才能发布）。

排课求解、规则维护、调课、审批发布、回滚等核心功能在本地模式下全部可用，`verify()` 恒通过（「本地模式默认可用，无需测试连接」），设置页徽章恒为「已启用」。

## 与外部平台的关系

本地数据库是唯一数据源，接不接外部平台只影响**数据外发**：之后随时可以在设置页接入飞书等平台，把主数据与课表同步外发，已有数据不受影响；解除连接也只删除绑定与令牌，不删除本地数据。

## 何时需要接入外部平台

| 需求 | 本地模式的现状 | 接平台后的能力 |
| --- | --- | --- |
| 教师查看课表并检查忙闲冲突 | 在系统内查看课表 | 「日历下发」：教师忙闲校验 + 日程创建到飞书日历 |
| 学生/家长/领导查看课表 | 系统内的展示与通知 | 同步到多维表格/妙搭公开链接，免登录分发 |
| 发布审批走组织已有流程 | 系统内置审批流 | 平台审批代理提交（各集成实现进度见[集成矩阵](README.md)） |

一句话排课的自然语言理解由平台无关的 OpenAI-compatible 模型通道提供（设置 → AI 模型），不属于任何外部平台依赖。

> 能力声明说明：v1 本地模式 manifest 声明 `table_store` 与 `notifier` 两项既有内置能力；审批与自然语言由系统内置组件承担，对应能力接口在二期收敛消费接缝时接入（见 `backend/app/integrations/README.md`）。
