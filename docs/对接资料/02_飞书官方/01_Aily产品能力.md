# 飞书 Aily 产品能力

- 官方标题：欢迎使用「飞书 aily」：企业级智能体开发平台，定制你的 AI 专属工作助手
- 访问日期：2026-08-08
- 官方 URL：https://www.feishu.cn/content/3d5z9ttt

## 与本项目有关的能力

- 支持 AI 技能编排、知识与数据处理、效果调优和持续运营。
- 可接入飞书文档、多维表格、数据库等数据源，并提供企业权限控制。
- 支持工作流可视化编排、技能调用和多渠道发布。
- 可发布到飞书、Web 等渠道，并与企业业务系统集成。

## 项目边界（2026-08-14 修订）

普通飞书自建应用 `cli_...` 负责 OAuth、日历和多维表格，不等于 Aily 应用。Aily Run 仍需要
`spring_...__c`；只允许省略技能 ID 的接口仍未消除 Aily App ID 依赖。

当前产品由可配置 AI 模型负责自然语言理解和候选规则拆分，正式规则必须由教务确认，确定性排课由
CP-SAT 完成；Aily Workflow 在取得对应企业权限后可以作为高级通道接入。
