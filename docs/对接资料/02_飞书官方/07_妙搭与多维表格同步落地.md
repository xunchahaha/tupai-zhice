# 妙搭与多维表格同步落地

版本：2026-08-16

## 结论

本项目采用“一份课表明细 + 一张班级入口目录 + 一个妙搭公开应用”的结构：

```text
途排智策当前发布课表
  ├─> 飞书多维表格「课表」：逐课明细、每班筛选视图
  ├─> 飞书多维表格「班级链接索引」：每班一行入口
  └─> 妙搭数据库/公开应用：按班级稳定 ID 读取并展示
```

妙搭负责学生、家长和领导看到的页面；多维表格负责数据源、班级视图、入口目录和运营维护。
不要为每个班级创建一个妙搭应用，也不要把数千条课程明细复制到“班级入口表”。

## 官方能力与项目边界

飞书官方资料确认：

- 妙搭可以从多维表格导入/同步数据，并在妙搭数据表中配置索引和行级访问策略；
- 妙搭应用可以发布到互联网，是否需要登录由应用发布和租户策略共同决定；
- 多维表格支持单独分享视图，分享时保留该视图的筛选、排序和隐藏字段；
- 多维表格开放平台提供视图的创建、查询、更新和删除接口。

当前官方接口中没有发现稳定的“创建独立分享并返回互联网公开 URL”契约。因此系统可以自动
创建/维护班级视图和普通视图入口，但最终公开分享 URL 由管理员首次在飞书界面开启分享后回填。
系统不得把普通 Base URL 伪装成已经可供互联网访问的公开链接。

## 数据表分工

### 课表

`schedule`/“课表”保存当前发布版本的逐课明细。系统按 `班级标识` 创建班级网格视图，
按 `排序键` 升序，并隐藏内部业务线、日程账号、业务标识等不面向学生的字段。

### 班级链接索引

`public_class_links`/“班级链接索引”每个“课表方案 × 班级稳定 ID”仅一行：

| 字段 | 所有者 | 说明 |
| --- | --- | --- |
| 业务标识 | 系统 | 课表方案与班级稳定 ID 的不可读哈希键 |
| 课表版本 | 系统 | 当前公开版本，如 `V2` |
| 班级标识 | 系统 | `campus_id:class_business_id`，跨校区唯一 |
| 班级名称 | 系统 | 供运营识别，可随主数据更新 |
| 学生/家长妙搭链接 | 管理员 | 妙搭公开页最终 URL |
| 公开视图链接 | 管理员优先/系统兜底 | 管理员回填的独立分享 URL 优先；未回填时可显示普通视图入口 |
| 公开入口类型 | 管理员/系统推导 | 妙搭、多维表格视图、两者或待配置 |
| 访问模式 | 管理员 | 互联网公开、需登录、密码等实际策略 |
| 状态 | 管理员/系统推导 | 待配置、公开视图待确认、已配置、停用 |
| 更新时间 | 系统 | 当前公开版本的发布时间，不因手工重试漂移 |
| 失效时间 | 管理员 | 入口有效期 |
| 备注 | 管理员 | 运维说明 |

后续发布、回滚和手工同步必须保留管理员字段。远端已填写的公开分享 URL 优先于系统根据
`table_id`/`view_id` 生成的普通视图入口。

## 妙搭实施步骤

1. 在途排智策发布一套课表，并完成 `课表` 与 `班级链接索引` 同步。
2. 在妙搭创建一个公开应用，将“课表”和“班级链接索引”从多维表格同步到妙搭数据库。
3. 给课表数据建立 `班级标识 + 上课日期 + 开始时间` 索引。
4. 页面接收 `class_id` 参数，只查询 `班级标识 = class_id` 的记录，并按日期、开始时间排序。
5. 页面至少展示：班级名称、课程名称、日期、星期、开始/结束时间、教师展示名、教室名称、
   当前版本和最后更新时间；调课通知独立放在课表上方。
6. 配置妙搭发布范围、登录要求和行级访问策略，完成一次学生/家长视角验收。
7. 把最终公开 URL 回填到“班级链接索引”的“学生/家长妙搭链接”；如同时开放飞书独立视图，
   把最终分享 URL 回填到“公开视图链接”。
8. 后续排课只更新数据，不重新创建应用。班级停用时把目录状态改为“停用”并处理旧链接。

## 建议展示内容

面向学生/家长：

- 班级名称、当前课表版本和更新时间；
- 日期、星期、上课时间、课程、教师展示名、教室；
- 本次相对上一公开版本的调课通知；
- “以本页面最新版本为准”的统一说明。

面向领导/管理人员：

- 总课次、覆盖日期、班级数、调整课次；
- 教师负荷分布、教室时段热力、软约束满足率；
- 最近 24 小时飞书同步成功率、写入量、平均耗时和失败资源。

不得在公开页面展示教师账号、手机号、内部业务 ID、排课日志、规则原文、授权令牌或未脱敏备注。

## 运维检查

- 同步后“班级链接索引”行数应接近当前已发布班级数，不应等于课表明细条数；
- 同一班级重复同步后仍只有一条业务标识；
- V1 → V2 后普通课表行更新，不新增第二套 4,000+ 行；
- 管理员填写的妙搭 URL、公开视图 URL、访问模式、失效时间和备注保持不变；
- 公开链接必须以未登录/学生身份实测，普通视图入口不等于互联网公开分享；
- 旧版“班级公开课表”先备份，再压缩或清理，停止作为学生入口。
