# 途排智策飞书生产接入

## 1. 创建飞书自建应用

1. 打开[飞书开放平台](https://open.feishu.cn/app/)，创建企业自建应用。
2. 记录 `App ID` 和 `App Secret`。
3. 在权限管理中申请多维表格记录的读取、写入权限，并完成企业管理员审批。
4. 发布应用版本，使服务端应用凭据生效。

官方鉴权说明：[tenant_access_token](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)。

## 2. 创建多维表格与字段

创建一个生产多维表格，为以下资源分别建立数据表，记录每张表的 `table_id`：

| 资源 | 建议数据表 | 写入方向 |
| --- | --- | --- |
| teachers | 教师 | 途排智策 → 飞书 |
| class_groups | 班级 | 途排智策 → 飞书 |
| rooms | 教室 | 途排智策 → 飞书 |
| time_slots | 时段 | 途排智策 → 飞书 |
| course_sessions | 课程场次 | 途排智策 → 飞书 |
| rules | 规则 | 双向预览，生产发布前人工确认 |
| schedule | 课表 | 途排智策 → 飞书 |

多维表格的 `app_token` 来自表格地址；`table_id` 来自具体数据表标识。字段名称需要与后端导出的中文字段保持一致。

## 3. 配置后端环境变量

复制 `backend/.env.example` 为 `backend/.env`，填写真实值：

```dotenv
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=真实密钥
FEISHU_BITABLE_APP_TOKEN=bascnxxx
FEISHU_TABLE_MAP={"teachers":"tblxxx","class_groups":"tblxxx","rooms":"tblxxx","time_slots":"tblxxx","course_sessions":"tblxxx","rules":"tblxxx","schedule":"tblxxx"}
```

密钥只进入部署环境变量，不提交到 Git，不写入前端代码。

## 4. 管理端检查与同步

1. 重启后端服务。
2. 进入“飞书集成”。
3. 点击“检查连接”。
4. 页面同时显示应用凭据验证状态和数据表映射完成状态。
5. 两项均完成后，“执行同步”按钮才可用。
6. 先导出教师、班级、教室、时段、课程场次，再导出课表；导入操作只对已配置的数据表发起真实读取。

官方记录接口：[读取记录](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-record/list)；[批量新增记录](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-record/batch_create)。

未完成配置时，系统只展示配置引导并阻断同步请求，不创建虚假同步记录。
