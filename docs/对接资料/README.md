# 途排智策对接资料

本目录只保留实现和飞书对接需要的技术材料。

## 目录说明

- `02_飞书官方`：Aily、多维表格、工作流、鉴权和服务端 API 的官方来源卡片。
- `03_算法与标准`：CP-SAT、排课 benchmark、隐私和教育数据治理资料。
- `04_接口与数据字典`：后端 DTO、Aily Skill、飞书字段映射和前端选型。
- `manifest.json`：文件路径、大小、SHA-256 和生成时间。

外部网页快照采用“标题、访问日期、关键约束、原始 URL”的 Markdown 形式，便于后续 Agent 引用并避免把持续更新页面误当成固定版本。

飞书生产接入以 `02_飞书官方/04_生产接入操作手册.md` 为实施入口，以带日期的 `05_官方契约核对记录_2026-08-10.md` 为当前官方证据。旧示例与核对记录冲突时，先重新打开官方页面复核，再更新核对记录和实现。
当前代码对应的环境变量、接口、数据表和故障处理见 `02_飞书官方/06_生产接入实现与运维.md`。
妙搭公开应用、班级筛选视图和“班级链接索引”的数据流与人工回填边界见
`02_飞书官方/07_妙搭与多维表格同步落地.md`。
后端鉴权请求头、多课表权限、求解参数、版本/回滚、同步和总览统计接口见
`04_接口与数据字典/后端接口与运行约定.md`。
