# 途排智策对接资料

本目录只保留实现、飞书对接和答辩需要的权威材料。原始比赛目录保持不变，`01_赛事与需求` 中的文件是复制件。

## 目录说明

- `01_赛事与需求`：正式规则、报名版开题报告、最终 DOCX/PDF/XLSX、研究与答辩材料。
- `02_飞书官方`：Aily、多维表格、工作流、鉴权和服务端 API 的官方来源卡片。
- `03_算法与标准`：CP-SAT、排课 benchmark、隐私和教育数据治理资料。
- `04_接口与数据字典`：后端 DTO、Aily Skill、飞书字段映射和前端选型。
- `manifest.json`：文件路径、大小、SHA-256 和生成时间。

外部网页快照采用“标题、访问日期、关键约束、原始 URL”的 Markdown 形式，便于后续 Agent 引用并避免把持续更新页面误当成固定版本。
