# 前端选型调研

## grok2api

核验仓库：https://github.com/chenyme/grok2api

前端采用 React 19、TypeScript、Vite、Tailwind CSS、shadcn/ui New York、Radix UI、TanStack Query、React Hook Form、Zod、Recharts 和 Lucide。项目按 `app/features/entities/shared` 分层，适合作为途排智策管理端的工程参考。

本项目复用技术路线和紧凑管理端交互，不复制 grok2api 的业务代码或页面。

## miuix

核验仓库：https://github.com/compose-miuix-ui/miuix

该项目是 Kotlin Compose Multiplatform UI 库，可覆盖 Android、iOS、桌面和 Web JsCanvas/WasmJs，并明确标注实验阶段。它不是 Flutter 组件库。对于表格、表单、课表网格和飞书内嵌 Web 场景，React DOM 方案的交付风险更低。

## 决策

首版采用 React Web 管理端。桌面端提供全部排课能力；移动端主要支持查看、确认和审批。后端 OpenAPI 保持平台无关，未来增加移动客户端时无需修改领域接口。
