`public_class_schedule` 是旧版兼容资源。它不再作为默认同步表，也不再承担学生入口；公开入口统一从
`课表` 的班级筛选视图和 `班级链接索引` 获取。

字段类型以 `backend/app/services/feishu.py::TABLE_SCHEMAS` 为准：类型 `1` 为文本，类型 `2` 为数字，
首列固定为文本“业务标识”。升级既有 Base 时，后端先读取表和字段，缺少的字段才追加，不会因为本地
绑定缺失而新建第二个多维表格。旧表的历史字段不会被自动删除。

## 规则状态

`draft -> awaiting_confirmation -> active/rejected -> retired`

未经确认的规则不进入正式求解。每次确认保存确认人、原文、结构化结果、来源和版本。

## 求解版本

每次运行保存数据快照校验和、规则版本、随机种子、时限、状态、objective、best bound、耗时和代码版本。调课版本通过 `parent_id` 关联旧课表。

## 课表方案与权限

- `schedule_sets`：每套课表的稳定 ID、编号、可修改名称、显示顺序和启用状态；
- `schedule_set_members`：用户在指定课表方案内的 `viewer`、`scheduler`、`approver` 权限；
- 管理员默认管理全部课表，成员权限不能高于账号全局角色；
- 主数据、规则、快照、求解、版本、调课、飞书工作区和同步日志均按 `schedule_set_id` 隔离；
- 请求头统一使用 `X-Schedule-Set-Id`，多方案时不得依赖示例名或固定 `default`。

## 求解日期参数与时间

- `date_from`、`date_to` 选中原始课次（含边界），并作为所有候选日期的全局下限/上限。
- `date_window_days` 以每节课原始日期为中心生成对称移动窗口，默认 7 天，上限 31 天；锁定课次固定在原日期，规则日期范围还会进一步收窄窗口。
- `time_limit_seconds` 控制求解器运行时间（1–900 秒）。超时结果只记录状态和目标界，发布仍须由用户显式执行。
- `room_no_overlap`、`teacher_no_overlap` 是后端强制补齐的系统硬约束；即便请求省略也会进入求解载荷。

业务数据库及 API 展示时间统一 `Asia/Shanghai`（UTC+8）；OAuth/JWT 过期判断等协议内部使用 UTC
瞬间，序列化到业务响应或飞书日历时才转换到 UTC+8。

## 同步原则

- 以业务 ID 匹配记录，禁止把飞书 record ID 当成领域主键。
- `app_token`、`table_id` 和 record ID 由系统自动创建并保存，不要求管理员逐项提供。
- 首次写入前分页查询业务 ID（每页 500）；缺失记录批量新增，已有记录批量更新（每批 1,000），重试先对账，不得产生重复行。
- 公开投影资源的非当前、重复和无业务标识行由系统按绑定台账清理（每批 500）；缺少 `base:record:delete` 时只记录待清理数量，不阻断主同步。
- 当前自动建表只使用文本（类型 1）和数字（类型 2）字段；班型、教师、规则对象等多值数据按资源约定用 `|` 或 ` / ` 展平，不能把飞书 record ID 当作关联主键。
- 同步日志记录资源、远端已有数量、新增数、更新数、写入数、飞书请求日志 ID 和错误，不记录令牌或应用密钥。
- `课表` 保留课程明细；`班级链接索引` 只保存每个班级的入口链接，一班一行，不复制课程明细。
- 妙搭链接和公开视图链接由管理员在首次创建/发布应用后回填（视图入口由系统按班级生成，首次公开分享需在飞书界面完成）；后续同步保留手工填写的链接、访问模式、状态、失效时间和备注。
- `公开展示汇总`、`公开调课通知`、`班级链接索引` 是系统拥有的公开投影；当前没有发布版本时不输出课程明细，调课通知只输出相对上一个已发布版本真正变化的课次。
- 公开演示只使用 `data/imports/sample.xlsx` 的匿名模拟数据。

## 总览统计 DTO

`GET /api/v1/overview/analytics` 返回以下四个统计块，不写入新业务表：

| DTO | 关键字段 | 统计口径 |
| --- | --- | --- |
| `teacher_workload` | `campus_id/name`、`total_teachers`、`assigned_teachers`、`total_sessions`、`total_hours`、`top_teachers`、`buckets` | 当前方案指定版本/日期范围；按校区+教师标识隔离，小时按课程实际时长汇总 |
| `room_heatmap` | `cells` 的课节明细；`period_cells` 的周一至周日×上午/下午/晚自习 7×3 汇总；`effective_date_from/to`、占用/可用教室时段和 `occupancy_rate` | 已发布 assignments ÷ 启用教室×完整日历区间；空闲日期保留在分母 |
| `optimization_penalties` | `objective_value`、`best_bound`、`total_soft_penalty`、`unattributed_objective_value`、`reconciliation_error`、`breakdown_source`、`scope_source`、`soft_constraints` | 仅在该次求解课次范围内重算；新运行用持久化范围，历史运行按请求条件重建；内建目标单独列为未归因值 |
| `sync_health` | `window_start/end`、成功/失败数、`records_read/written`、`retry_count`、`average_duration_ms` | 当前方案指定回看窗口，默认最近 24 小时 |

统计接口没有发布版本或没有可重算的软规则时返回空集合和说明；零个可评估样本的满足率为
`null`，不得填成 100%。同步平均耗时和重试数只汇总日志中实际记录的样本。
