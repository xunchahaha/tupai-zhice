# 数据字典与飞书映射

| 后端资源 | 飞书“业务标识” | 中文字段 | 自动创建表名 |
| --- | --- | --- | --- |
| teachers | 教师业务 ID | 教师名称、学科、周最大课时、不可用时段、偏好时段、数据级别 | 教师 |
| class_groups | 班级业务 ID | 班级名称、年级、学科、学生数、优先级、设备需求、教师标识 | 班级 |
| rooms | 教室业务 ID | 教室名称、容量、设备、可用时段、是否启用 | 教室 |
| time_slots | 时段业务 ID | 星期、开始时间、结束时间、类型、顺序、是否开放 | 时段 |
| course_sessions | 场次业务 ID | 班级标识、教师标识、学科、学生数、设备需求、时长分钟、建议时段、是否锁定 | 课程场次 |
| rules | 规则业务 ID | 规则原文、作用对象、约束类型、约束范围、硬软类型、权重、状态、版本、来源文档 | 规则 |
| schedule | 版本 ID + 场次业务 ID | 版本、当前版本标记、发布状态、场次、班级、教师、学科、时段、教室、变更类型 | 课表 |

## 规则状态

`draft -> awaiting_confirmation -> active/rejected -> retired`

未经确认的规则不进入正式求解。每次确认保存确认人、原文、结构化结果、来源和版本。

## 求解版本

每次运行保存数据快照校验和、规则版本、随机种子、时限、状态、objective、best bound、耗时和代码版本。调课版本通过 `parent_id` 关联旧课表。

## 同步原则

- 以业务 ID 匹配记录，禁止把飞书 record ID 当成领域主键。
- `app_token`、`table_id` 和 record ID 由系统自动创建并保存，不要求管理员逐项提供。
- 首次写入前查询业务 ID；缺失记录批量新增，已有记录批量更新，重试不得产生重复行。
- 多值字段在飞书中优先使用多选或关联字段；XLSX 中使用 `|` 分隔。
- 同步日志记录资源、远端已有数量、新增数、更新数、写入数、飞书请求日志 ID 和错误，不记录令牌或应用密钥。
- 公开演示只使用 `data/imports/sample.xlsx` 的匿名模拟数据。
