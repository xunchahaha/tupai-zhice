# 数据字典与飞书映射

| 后端资源 | 业务主键 | 主要字段 | 飞书表建议名 |
| --- | --- | --- | --- |
| teachers | 教师ID | 名称、学科、周最大课时、不可用时段、偏好时段 | 教师 |
| class_groups | 班级ID | 名称、年级、学生数、设备需求、教师ID | 班级 |
| rooms | 教室ID | 名称、容量、设备、可用时段、状态 | 教室 |
| time_slots | 时段ID | 星期、开始、结束、类型、是否开放 | 时段 |
| course_sessions | 场次ID | 班级ID、教师ID、人数、设备、时长 | 课程场次 |
| rules | 规则ID | 原文、对象、类型、硬软、范围、权重、来源、状态、版本 | 规则 |
| schedule | 版本+场次ID | 时段ID、教室ID、变更状态、发布状态 | 课表 |

## 规则状态

`draft -> awaiting_confirmation -> active/rejected -> retired`

未经确认的规则不进入正式求解。每次确认保存确认人、原文、结构化结果、来源和版本。

## 求解版本

每次运行保存数据快照校验和、规则版本、随机种子、时限、状态、objective、best bound、耗时和代码版本。调课版本通过 `parent_id` 关联旧课表。

## 同步原则

- 以业务 ID 匹配记录，禁止把飞书 record ID 当成领域主键。
- 多值字段在飞书中优先使用多选或关联字段；XLSX 中使用 `|` 分隔。
- 同步日志记录方向、资源、模式、读取/写入数量和错误，不记录密钥。
- 公开演示只使用 `data/imports/sample.xlsx` 的匿名模拟数据。
